# Homepage church artwork

Created with the built-in imagegen tool from the user-provided church photograph. WebP exports preserve the generated transparency; the original PNGs remain in the local generated-images library.

- `day.webp`: daylight, unlit blue glass.
- `night.webp`: matching evening composition, illuminated amber windows.

The homepage selects the image using the app's reading theme. Both assets are 1536 × 1024, so switching themes preserves layout.

## Prompt set

Day: Transform the supplied church photo into a tasteful editorial illustration with simplified shapes, subtle texture, sage foliage, muted terracotta brick, cream paths and taupe roofs. Preserve the broad low peaked roof, roof cross, projecting central facade with the circular cross window, side wings and framing trees. Use a compact 3:2 landscape vignette, soft daylight and unlit blue windows. Transparent exterior; no cars, HVAC units, extraneous buildings, text or watermarks.

Night: Edit the generated day illustration, preserving architecture, framing, trees, crosses, paths, dimensions and style. Change only lighting and colors for twilight, with darker roofs, brick and foliage. Illuminate the circular window, upper and vertical windows, and entry glass in warm amber, retaining pane details and a restrained glow. Preserve the transparent exterior; no additional objects or text.
